# Generative Design & Topology Optimization Pipeline

This repository is dedicated to structural Finite Element Analysis (FEA) and Topology Optimization (TO) using pure Python, with a focus on code-driven CAD generative design. 

The primary goal of this codebase is to provide an ultra-fast, robust, **fully in-memory 3D elasticity solver natively on Windows**. By eliminating heavy `.inp` and `.dat` file I/O overhead typical of external solvers (like CalculiX), the tools in this repository allow for rapid, iterative SIMP (Solid Isotropic Material with Penalization) loops directly in RAM.

## 🚀 Core Technologies

- **Gmsh**: Automates boundary extraction, CAD geometry healing, and high-speed tetrahedral 3D meshing.
- **scikit-fem**: Handles pure Python, memory-native assembly of complex continuous Galerkin stiffness matrices and exact mathematical continuous facet integrals (surface tractions, hydrostatic pressures).
- **PyPardiso**: Under-the-hood Intel MKL Pardiso engine enabling blazing-fast, direct in-memory factorization and solving of large-scale 3D topologies natively on Windows.
- **PyVista / Meshio**: Warps, renders, and exports volumetric XDMF data directly to ParaView.

## 📂 Codebase Structure

### In-Memory Solvers (Active Workflow)
* **`run_fea_skfem.py`**  
  The flagship, fully-integrated, native Python 3D FEA solver. 
  - Direct STEP file import and mathematical healing (`fin_assembly_links.step`).
  - Assembles exact continuous FEniCSx-style boundary conditions (hydrostatic pressure fields and tip tractions) using `FacetBasis` interpolation.
  - Leverages pure `numpy` tensor ops and `pypardiso` to solve 40k+ DOFs in fractions of a second completely in RAM.
  - Automatically exports `in_memory_results.xdmf` and generates presentation-ready warped visualizations of displacement and Von Mises stress via `PyVista`.
  - **Ready for SIMP Integration.**

### Legacy & File-I/O Solvers
* **`run_fea.py`** & **`run_fea_draft.py`**  
  CalculiX-based backend (`ccx.exe`) scripts. While heavily multithreaded and Pardiso-accelerated, these approaches rely on writing `.inp` decks to disk and scraping `.dat` / `.frd` outputs, inherently bottlenecking fast thousands-of-iterations Topology Optimization loops.
* **`run_fenicsx_to.py`**  
  The reference FEniCSx TopOpt implementation. Highly exact mathematically but restrictive regarding native Windows/Conda environments (often requiring WSL or Linux).
* **`visualize_fenicsx_fea.py`**  
  FEniCSx visualization reference scripting.

### CAD & Geometry
* **`fin_assembly_links.step`**  
  The core generative design boundary envelope/assembly being optimized.
* **`satvik_fin_fixed_rotated.step`** / **`wing_skeleton_v3.step`**  
  Auxiliary/legacy structural test geometries.
* **`fin_assembly_links.py`**  
  Procedural/code-driven CAD generation logic.

### Outputs
* **`fea_results/`**  
  The output directory for all exported XDMF volumetric datasets and `.png` visual plots. (This directory is explicitly cleaned to only hold results generated by the current active `run_fea_skfem.py` workflow).

## 📊 Workflow
1. **Model Import:** A STEP file is loaded and mapped into physical bounds.
2. **Meshing:** Unstructured tetrahedral grids are built dynamically based on physical sizing requirements.
3. **FEA Solve:** Matrices are assembled dynamically with mathematically exact tractions. Intel MKL processes the deformations and computes the continuous tensor fields (Von Mises / FoS).
4. **Topology Optimization (WIP):** Element densities are targeted via SIMP penalty algorithms to achieve specific target volume fractions while minimizing overall strain energy.
